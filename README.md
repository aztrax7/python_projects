# Python Projects 🐍

**A collection of small Python experiments, from printing bills to making patterns that somehow take 20 lines of code.**

This repo is basically a timeline of me learning Python, one notebook at a time. Some projects are practical, some are purely for experimenting, and a few exist because I wanted to see what a particular loop could actually do.

They're beginner-level programs, and that's the point. Before building bigger applications, I wanted to get comfortable with the fundamentals and actually *use* them instead of just reading about them.

## What's in here?

| Project | What it does | Main concepts |
| --- | --- | --- |
| **[Bill Generator](1%29%20bill_generator)** | Creates an itemized bill, calculates subtotal and 18% GST, and adds a timestamp. | Inputs, arithmetic, formatting |
| **[Triangle Calculator](2%29%20triangle_calculator)** | Checks triangle validity and classifies triangles by their sides. | Conditionals, mathematical logic |
| **[Equality Checker & Others](3%29%20equality_checker_%26_others)** | Includes number comparisons, an electricity-bill calculator, multiplication tables, and other short exercises. | Conditions, loops |
| **[Turtle Design & For Loops](4%29%20turtle_design_%26_for_loops)** | Uses Turtle graphics to draw a geometric pattern, alongside nested-loop exercises. | Turtle, iteration, nested loops |
| **[For-Loop Operations](5%29%20for_loop_operations)** | Creates star patterns, number sequences, and pyramids. | For loops, ranges, formatting |
| **[While-Loop Operations](6%29%20while_loop_operations)** | A separate notebook for practicing while-loop logic. | While loops |
| **[Dictionary Operations](7%29%20dictionary_operations)** | Exercises focused on Python dictionaries. | Dictionaries |

Each folder contains a Jupyter Notebook (`.ipynb`). Several folders also have their own README with more details and sample outputs.

## A few highlights

**The bill generator** was a nice introduction to writing something with a practical output. It takes item names, quantities, and prices, then prints a bill with tax included. Nothing revolutionary, but getting the formatting right was satisfying.

**The triangle calculator** made me turn a familiar math topic into actual program logic. The code checks whether the sides and angles meet the rules before deciding what kind of triangle you've entered.

**The Turtle graphics notebook** was where coding felt a little less like solving a worksheet. Instead of just printing numbers, I could watch a pattern take shape on screen.

And yes, there are quite a few loop exercises. You'd be surprised how much thinking can go into getting a pyramid of stars to line up properly.

## How to run the notebooks

You'll need **Python 3** and a way to open Jupyter Notebooks, such as **JupyterLab**, **Jupyter Notebook**, or **VS Code with the Jupyter extension**.

Clone the repository:

```bash
git clone https://github.com/aztrax7/python_projects.git
cd python_projects
```

Open the folder you want, launch its `.ipynb` notebook, and run the cells in order. You can also view the notebooks directly on GitHub without running them.

Most examples use basic Python features. A few may need additional libraries, such as `pytz` for the bill generator; the individual project READMEs contain relevant notes. Turtle graphics may also need a local desktop environment to display its drawing window.

## What I learned

Working through these notebooks helped me get comfortable with:

- Variables, inputs, data types, and arithmetic
- `if`/`elif`/`else` statements and basic input validation
- `for` and `while` loops, including nested loops
- Lists and dictionaries
- Formatting terminal output
- Turning mathematical rules into code
- A little creative programming with Turtle

The biggest lesson? Understanding syntax is one thing. Figuring out **how to turn an idea into steps a computer can actually follow** is another.

## Why this repository exists

I wanted somewhere to keep my early Python work rather than leaving everything scattered across different notebooks.

This isn't meant to be a collection of advanced software projects. It's a record of the smaller exercises that helped me build confidence with Python and eventually move on to larger programs.

If you're learning Python too, feel free to explore the notebooks, run them, and change things. Breaking a small program and figuring out why is half the learning experience anyway.
